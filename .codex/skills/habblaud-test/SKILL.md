Na raiz do Habblaud, use Node.js 22.12 ou superior. Se faltarem dependências, rode `npm ci`.
Rode `npm run typecheck`, `npm run i18n:check` e `npm test`. Para investigar um teste, passe seu caminho com `npm test -- caminho`.
